## 六、风险与权衡

1. **Q5 不引 Jinja2**：HTML 报告须用 `string.Template` 或作为可选依赖。**评审 R3 修正**：`string.Template` 无循环/条件，动态漏洞表格尴尬，等于没用模板。应在 Phase 1 即**提前决断**——接受可选依赖插件（引 Jinja2 须重新裁决）或用 Python data-driven + f-string 直接生成；不把分歧拖到 Phase 2 才暴露。
2. **X2 WAF 绕过默认关**：`waf_bypass.py` 已实现（F1），接线但绝不进 MVP 主链路，避免改变 Out-of-Scope 边界。
3. **X3 无云**：观星告警用本地 webhook/文件（**邮件砍掉，R4**），不引入服务端/Postgres/Redis，守"无外部依赖"。
4. **准确率 vs 速度**：三层降噪为差异化竞争力，**不可为提速牺牲假阳性控制**（UserStory 核心诉求）。
5. **CVE 库扩展纪律**：任何新增/修改 CVE 条目须经 D1 治理脚本校验，禁止虚构/错挂；**治理脚本计数作指标非门禁**（避免模板同步致 215 漂移误杀）。
6. **新增 — GuanXing schema 演进**：告警/导出会改 SQLite schema，WAL 只解决并发不解决演进，应在 `db.py` 加 schema 版本 + 轻量迁移，避免升级后旧库不可读。
7. **新增 — CI 选型**：明确 CI = **GitHub Actions**（本项目已建 GitHub 仓库 `xiabai2004/poxiao`），矩阵 Python 3.10+；CI 须先 `pip install -e .` 解决 `src.*` 导入（本地依赖 `poxiao.py` 的 `sys.path.insert`，云端无此上下文）。
