### 2.2 未知变量 top15（多为模板自定义变量，非缺口）

## 三、升级路线（按 ROI 排序）

### 1. raw 请求支持（P2-1，✅ 已于 2026-08-08 落地）
- 解析 nuclei `raw` 字段（HTTP 报文文本：`GET /path HTTP/1.1\nHost: {{Hostname}}`）
- 引擎 `_execute_request` 增加 raw 模式：解析请求行/头/体 → 构造 httpx 请求
- 支持 `{{Host}}`（URL 主机）、`{{Hostname}}` 变量
- **落地结果**：11,144 模板中 11,137 可加载（99.9%），3,401 个 raw 模板成功执行

### 2. DSL 函数子集（P2-2，✅ 已于 2026-08-08 落地）
- 实现 ~26 个白名单函数：to_lower/to_upper/base64/base64_decode/md5/sha1/sha256/rand_int/rand_base/contains/icontains/starts_with/ends_with/len/trim/replace/concat/substr/url_encode/url_decode/hex_encode/hex_decode/regex/printable/rand_char
- 支持嵌套调用（8 层上限）、`&&`/`||` 组合、引号内逗号参数
- 安全边界：白名单求值器无 eval，未知函数/危险关键字不匹配
- **落地结果**：67,601 个 dsl matcher 的表达式可解析率大幅提升（未覆盖的 nuclei 专有函数保持安全不匹配）

### 3. 模板级 max-redirects 等参数（P2-3，✅ 已于 2026-08-08 落地）
- 确认 max-redirects 为 AsyncClient 构造参数，cookie_client 创建时已按模板生效；修正 request() 误传 TypeError

### 4. 精选合入策略（P2-4，持续）
- 从 community 目录人工精选高价值模板（CVE 热榜/国内组件）进正式 `templates/`
- 走 `template_sync validate` + P1-C 签名 + `compat` 三关
- 目标：正式库 224 → 500+

### 5. 全量启用（P2-5，远期）
- raw + DSL 补齐后，`templates-community/` 全量 11k 模板可用
- `poc scan --include-community` 显式启用（社区库标注实验性）

## 四、风险与权衡

| 风险 | 对策 |
|------|------|
| raw 模板含 payload 轰炸（SQLi/XSS 扫描型），大量启用后误报上升，**侵蚀三层降噪卖点** | 社区库默认关闭；正式库人工精选；降噪层对 poc 结果复用 |
| DSL 函数实现偏差导致漏报/误报 | 函数实现后对 67k 表达式抽样回归；保持白名单 |
| nuclei-templates 更新频率高（每日） | `sync` 一键重拉 + `compat` 统计 + 签名重签 |
| 供应链投毒 | P1-C 签名强制（正式库）；社区库警告提示 |

---

## 五、结论

- **短期**（本轮已具备）：sync 拉取 + 严格 compat 统计 + 11k 模板离线可用
- **中期**：raw + DSL 函数子集（解锁 90%+ 兼容率），正式库精选至 500+
- **长期**：社区库全量启用（`--include-community`），模板生态对标 afrog 活跃度
