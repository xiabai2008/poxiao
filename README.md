# 破晓 (PoXiao)

Bug Bounty 辅助工具 — 专为国内 SRC 挖洞场景打造。

## 原则

- 少即是多：不追求模块数量，追求每次扫描出至少一个可提交漏洞
- 结果可操作：不只是报告"发现漏洞"，还要告诉你怎么验证、怎么利用
- 渐进输出：扫完一个目标出一个报告，不等全部
- 目标管理：支持大规模目标列表 + 去重 + 存活检测

## 目录结构

```
破晓/
├── src/              # 核心源码
│   ├── scanner/      # 扫描引擎
│   ├── target/       # 目标管理
│   ├── reporter/     # 报告生成
│   └── utils/        # 工具函数
├── configs/          # 配置文件
├── scripts/          # 实用脚本
├── data/             # 数据文件
└── scan_results/     # 扫描结果
```
